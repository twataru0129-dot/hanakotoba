# 🌸 花言葉 v1.1

**想いにぴったりの花を見つけよう**

花の名前・花言葉・気持ち・贈る相手・シーン・五十音・誕生日・月から花を探せる「花言葉図鑑」Webアプリです。
iPhone での利用を最優先にした、静的ファイルだけで動く SPA です（サーバー・npm・ビルド不要）。

## 収録内容

- **371種類**の花・植物（v1.0 の70種類 ＋ v1.1 で追加した301種類）
  - 収録数はホーム画面と「このアプリについて」に `FLOWERS.length` から自動表示されます
- **366日分の誕生花**（2月29日を含む）

## おもな機能

| 機能 | 内容 |
| --- | --- |
| 検索 | 名前・読み・**別名（aliases）**・花言葉・**色別の花言葉**・カテゴリーから検索。ひらがな/カタカナの違いも吸収（例：「薔薇」「ローズ」→バラ、「情熱」→バラ） |
| 花から探す／花言葉から探す | 全花の一覧、花言葉の部分一致検索 |
| 気持ち・贈る相手・シーン・五十音から探す | v1.0 と同じ |
| 🎂 誕生日から探す | 月 → 日を選ぶと「○月○日の誕生花」を表示。2月は常に29日まで選べます |
| 📅 誕生花カレンダー | 月ごとに1日〜末日の誕生花を一覧。日付をタップで誕生花の画面へ |
| 🌷 月から探す | 「その月に咲く花」と「その月の誕生花」をタブで切り替え |
| 今日の花／今日の誕生花 | 今日の花は v1.0 と同じ仕組み。今日の誕生花は端末の日付から表示 |
| 花の詳細 | 花言葉・**色別の花言葉**・由来・**誕生花の日付（タップで移動）**・開花時期・**季節**・**別名**・豆知識。情報がない項目は表示しません |
| お気に入り・ランダム・シェア | v1.0 と同じ（お気に入りの保存形式・花 id は変更していません） |

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の骨組み・アイコン / manifest の設定 |
| `style.css` | デザイン（safe-area・横画面・PC 対応） |
| `app.js` | 画面遷移・検索・今日の花・誕生花・お気に入り・シェア（バージョンは `APP.version`） |
| `flowers.js` | 花データ。花の追加・修正はここ |
| `birthdays.js` | 誕生花データ（`"MM-DD"` → 花 id の配列、366日分） |

| `manifest.json` | ホーム画面追加 / PWA 用設定 |

| `tools/check-data.js` | 開発用のデータ整合性チェック（アプリには含まれません） |

## データの考え方

- **1つの植物＝1件**。色違いは別の花にせず、`colorMeanings` にまとめます（赤いバラ → バラの色別花言葉）。
- 漢字表記・別名は `aliases` に入れます（例：バラ → `薔薇`, `ローズ`, `ミニバラ`）。検索で同じ花が見つかります。
- 開花時期は `bloomingMonths`（1〜12の配列）。「月から探す」と季節（春夏秋冬）の表示はここから自動で作ります。
- **誕生花の日付は `birthdays.js` だけ**で管理し、花 id で参照します。花の詳細に出る日付や「○月の誕生花」は自動で作られるので、`flowers.js` に日付を書く必要はありません。
- 日付は年に依存しない `"MM-DD"` 形式です（`"02-29"` を含む）。

## 花を追加する方法

1. `flowers.js` の配列に1件追加します（項目の説明はファイル冒頭のコメントを参照）。
   - 追加の前に、同じ植物が別名で登録されていないか検索してください。
   - `id` は英字で、一度公開したら変更しないでください（お気に入りが消えます）。
2. 誕生花にする場合は、`birthdays.js` の該当日付の配列に `id` を追加します。
3. 次のコマンドで重複や参照切れを確認できます（Node.js があれば実行できます。npm install は不要）。

```sh
node tools/check-data.js
```

チェック内容：id の重複、名前・別名の重複（同じ花の二重登録）、花言葉の重複、存在しない id の参照、366日の欠け、2月29日の有無、v1.0 の id が残っているか、など。

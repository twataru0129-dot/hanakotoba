# 花の写真フォルダ

このフォルダに `花のid.webp` という名前で写真を置くと、一覧カードと詳細画面に自動で表示されます。
（写真がない花は、イラストとグラデーションで表示されます）

例:

- `rose.webp` … バラ
- `sunflower.webp` … ひまわり
- `tulip.webp` … チューリップ

花の id は `flowers.js` の各データの `id` を確認してください。
webp 以外の形式を使う場合は、`flowers.js` の該当データに `image: 'rose.jpg'` のように書くと個別に指定できます。

- 推奨サイズ: 横 1200px 程度（縦横比は自由。中央付近が切り抜かれて表示されます）
- 権利関係が明確な写真（自分で撮影したもの、利用許諾のあるもの）だけを使ってください。
